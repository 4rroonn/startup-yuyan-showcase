
# Start-up Yuyan
### A Web-Based Startup Incubation Management System

**Academic Capstone Project | Southern Luzon State University**

Developed for the Southern Luzon State University Technology Business Incubator (SLSU-TBI) to support and centralize startup incubation management processes.

## Project Overview

Start-up Yuyan was designed to help manage startup applications, incubatee records, progress tracking, consultation scheduling, and administrative operations within the SLSU-TBI.

## Key Features

- **Application Management:** Submission, review, and processing of startup applications.
- **User Management:** Role-based user accounts and access control.
- **Progress Tracking:** Monitoring of startup activities and incubation curriculum progress.
- **Consultation Scheduling:** Requesting, reviewing, and managing consultation schedules.
- **Administrative Dashboard:** Overview of incubation activities and records.
- **Audit Logs:** Recording selected administrative and system activities.
